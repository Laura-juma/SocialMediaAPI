Welcome to the Social Media API

A RESTful API built with Django REST Framework that allows users to create posts, comment, like posts, follow users, and receive notifications.

API Endpoints

Authentication & Users

  • Register User
  • Login
  • Logout
  • My Profile
  • /api/accounts/profile/<user_id>/ - View User Profile
  • /api/accounts/follow/<user_id>/ - Follow User
  • /api/accounts/unfollow/<user_id>/ - Unfollow User

Posts & Comments

  • /api/posts/ - Create and View Posts
  • /api/posts/<id>/ - Retrieve, Update or Delete Post
  • /api/comments/ - Create and View Comments
  • /api/comments/<id>/ - Manage Comments

Social Features

  • /api/feed/ - View User Feed
  • /api/posts/<id>/like - Like a Post
  • /api/posts/<id>/unlike - Unlike a Post
  • /api/notifications/ - View Notifications

Technologies Used

  • Python
  • Django
  • Django REST Framework
  • Token Authentication
  • Render
